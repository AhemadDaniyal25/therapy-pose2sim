# numpy 2.5.2 / scipy 1.18.1 / cv2 5.0.0 / torch 2.14.1 and runs fine.
# Hard-pinning older versions here would DOWNGRADE that venv and break it.
# Use this file to build a NEW environment, not to "fix" an existing one.
#
# What actually matters is not a specific version but one pairing:
#
#     numpy >= 2.0  must go with  scipy >= 1.14
#     numpy <  2.0  must go with  scipy <  1.14
#
# Mismatch that pairing and you get `AttributeError: np.long` from deep
# inside Pose2Sim, which looks like a Pose2Sim bug and is not one.
# hpc/verify_hpc.py checks the pairing explicitly, so run that instead of
# trusting the version numbers by eye.
#
# Known-good combinations:
#   python 3.12 + numpy 2.5 + scipy 1.18 + cv2 5.0   (woody, Oct 2026)
#   python 3.10 + numpy 1.26 + scipy 1.11 + cv2 4.10 (tinygpu, Sep 2026)
